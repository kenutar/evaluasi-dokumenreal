Pembuat Prompt Evaluasi

Untuk semua jenis evaluasi: pilih jenis, pilih file, lalu salin prompt ke Claude dan lampirkan file yang sama. Aplikasi hanya membaca nama file; isi file tidak dibuka atau dikirim ke mana pun.

1. File template

Contoh hasil evaluasi yang bentuk dan naratifnya dipertahankan.

2. File konteks / data isi

Maksimal 3 file. Tentukan peran tiap file agar prompt menyebut sumber isi dengan tepat.

Maksimal 3 file, kelebihannya diabaikan.

3. File data surat referensi

Berisi nomor, tanggal, dan perihal surat yang dipakai sebagai narasi. Boleh dikosongkan.

Prompt singkat berdasarkan file

Hanya memakai file di atas, tanpa isian lain. Lebih presisi karena nama dan peran tiap file disebut.

4. Jenis evaluasi

Untuk prompt lengkap. Jenis yang dipilih mengisi panduan khusus di langkah 5, dan panduan itu bisa Bapak ubah.

5. Panduan dan detail

Prompt lengkap

Lampirkan semua file di atas saat mengirim prompt ini.
